# Exact two-state finite-step certificate

This directory is the machine-verifiable supplement for the two-state example
in `Endogenous Strategic Switching: Finite-Step Orbital Stability and Modal
Damping`, v0.13.

The manuscript's displayed six-decimal parameters are interpreted literally as
exact rational numbers. The verification script checks, using exact SymPy
rational arithmetic:

1. exact closure of the period-two orbit;
2. strict support selection at both cycle phases;
3. completeness of all support prefixes through horizon N=3 under the weak
   global-potential inequalities;
4. the five and only five feasible three-step support-sequence regions;
5. exact negative semidefiniteness of the contraction (`eta = 31/50`),
   radius-return (`r = 1/5`), and terminal-active-phase S-procedure matrices,
   via all principal minors of their negatives.

Files:
- `exact_parameters.csv`: exact rational input data.
- `feasible_witnesses.csv`: rational witnesses for the five feasible cells.
- `exact_multipliers.csv`: all nonzero rational S-procedure multipliers.
- `verify_exact_certificate.py`: standalone verifier.
- `verified_branch_tree.csv`: generated by the verifier.
- `verified_lmi_principal_minors.csv`: generated by the verifier.

Run:
    python verify_exact_certificate.py

Expected final line:
    ALL EXACT CHECKS PASSED

The exact arithmetic is a reproducibility device for this benchmark; it is not
required by Proposition 1 or by numerical SDP-based searches for certificates.
